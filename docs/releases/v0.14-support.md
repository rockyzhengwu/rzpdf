# v0.14 关联文件支持矩阵

本矩阵限定 Catalog／page 的 PDF 2.0 AF，不代表完整 ISO／PDF/A 符合性。V14-00～09／三个阶段已完成限定验收，见[验收记录](v0.14-acceptance.md)。

| 能力 | 读取 | 创建或修改 | 边界 |
|---|---|---|---|
| owner／快照 | 文档和实际页面，带 stamp | 不开放任意字典 owner | 任意 revision 后重新取 target／snapshot |
| AF 数组 | 直接／间接；直接或间接 Filespec | 新绑定为间接 Filespec 引用 | 最多 1024；重复间接身份／循环／坏类型拒绝；原顺序保留 |
| 名称／关系／MIME | UF 优先展示、原始关系名、选定 MIME | 五关系子集、显式 MIME、Unicode | 不从扩展名推断关系；其他关系只读保留 |
| payload | 显式预算提取；列表不解码 | 新建／从旧附件解码克隆 | F／UF 歧义、多平台 EF、外部路径访问拒绝 |
| Catalog／page 绑定 | 可分别读取 | 关联／解除、精确幂等 | 只改变一个 owner；旧数组别名与其他关联保留 |
| 附件名称及批注 | 旧 API 保持 | 移除名称／批注／AF 互不隐式删除 | 旧 attachment_data 取 F，annotation_file_data 优先 UF；AF profile 拒绝双载荷歧义 |
| 同文档页面操作 | 已有关联 | 复制、重排和删除的选定组合 | 可共享 Filespec；解除一页不影响其他页；未知回指仍拒绝 |
| 跨文档页面操作 | 页面可达图 | 一批导入、选页提取 | 一个批次保持共享；不合并源 Catalog AF／EmbeddedFiles；未选页回指、加密源及不兼容版本仍拒绝 |
| 全量保存 | Strict 重开 | Classic／xref stream／ObjStm，Preserve／Flate | 复用原默认；新 AF 生成要求有效 PDF 2.0 |
| unsigned 增量 | 原 source 及关联可读 | Classic／xref stream 的选定修改 | 原字节前缀保持，已存在的首 ID 和 Encrypt 身份保持；精确 no-op 返回原字节 |
| R6 | 已认证身份下读取 | content modify 允许的用户／owner 修改 | 受限 user 不因重复绑定或解除获得修改权；无新 handler／签名组合 |
| 签名和恢复 | 原有只读边界 | AF 写入仍拒绝签名来源；恢复无写方法 | 不扩大签后受控白名单，新增 compile-fail 证明 |

外部 Filespec 可列举但不打开或克隆；直接 Filespec 无稳定句柄，因此不提供按展示名称删除的替代接口。未知配置、私有键和现有关联的保留不构成语义认证。未知扩展按当前精确编辑／迁移保护保留或拒绝，不能静默丢掉相关字段。

新建／克隆不注册 EmbeddedFiles 名称；绑定 API 才建立 AF 关系。解除仅移除一个 owner 的链接，最后项移除 AF 键，不物理删除 Filespec／流／历史。无安全擦除、自动附件 UI、自动文件落盘或 payload 执行。

StructElem／图形对象／内容序列 MCAF／DPart、非嵌入文件创建、原位改写共享关系／载荷、XMP 同步、PDF/A 专项认证、图层迁移和扁平化继续不支持。[边界](v0.14-boundaries.md)的语法／预算上限和[指南](../associated-files.md)为公共 API 契约。
