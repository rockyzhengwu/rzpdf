## 实施顺序

先实现共用目标和树结构，再接导航与标签；随后交付批注与 AP、表单与 Widget。页面关系维护随各阶段推进，最后统一冻结源码验收，避免每次小改动重复全量测试。

每项需记录实现入口、正反用例、保存重开和独立验证结果。结构用 qpdf/独立 Python 阅读器检查，外观用 MuPDF 与本库渲染比较；不要求 Poppler。fuzz 按既定决定暂缓。

## 不包含

不实现 JS/XFA 执行、OCR、表格推断、通用排版、真正脱敏、签名扩展或 Tagged PDF 所有权迁移。未知对象保留；无法安全迁移的关系明确拒绝，不静默丢弃。

规范依据：[ISO 32000-1，7.9.6–7.9.7、12.3–12.7](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/PDF32000_2008.pdf)。实现基于规范，不复制第三方引擎代码。
