## 规则到实现的对应

- AF 是显式对象关系，不按名称树是否存在推断。读取、绑定与解除分别操作一个 Catalog／page，名称、批注及其他 owner 的生命周期独立。
- 关系和嵌入流类型进入校验，MIME 按已冻结语法检查；有 Params 的新绑定／克隆要求 ModDate。未知关系只读保留，生成仅五关系子集；不是完整标准关系枚举。
- 创建使用间接 Filespec 和 EmbeddedFile，F／UF 映射到同一载荷；不支持的外部、平台或加密载荷扩展明确拒绝，不发起访问或执行。
- 对版本、身份、预算、COW、保存、安全及迁移的数值和保护规则是本库的限定 API 契约，见[公共边界](v0.14-boundaries.md)，不冒称都是规范强制上限。

## 归档门槛更正

按本版限定规则完成来源核对与快照登记即可关闭 V14-00；完整原文归档另作资料任务。功能范围、完整回归、独立渲染和安全门禁均保持，不据此放宽已声明的标准规则或扩大符合性结论。
