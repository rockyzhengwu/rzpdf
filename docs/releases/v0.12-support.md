|---|---|---|

| xref stream 读取 | 已有，含 W/Index、Prev 和模式／限额检查 | 补齐新输出的闭环与独立投影，不重写已有读取器 |
| ObjStm 读取 | 已有，含 N/First、边界、类型和预算检查 | 用新生成容器验证成员身份、边界及重开编辑 |
| hybrid 读取 | 已有同 revision 流覆盖表、历史合并与限额；签名来源有额外拒绝 | 普通输出转换／增量纳入对照，签名限制不放宽 |
| 全量 xref stream，不打包 | 未加密及现有 R6 已验收，`SaveLayout::XrefStream` | W [1 8 4]／完整 Index；原版本／身份／权限契约，不静默移除保护，不开放线性化或签名重写 |
| 全量 xref stream + ObjStm | 未加密及 R6 已验收，`XrefStreamWithObjectStreams`；100 成员／1 MiB 双限额，支持原始或更小的 Flate | R6 容器压缩后加密一次；AES 分组预留 IV／padding；禁止／超大及不同默认 filter 的含字符串对象独立，保留 metadata／Identity 例外 |
| 全量布局／保护组合 | 四个显式组合入口；原布局默认 Preserve，Owner 可 Remove／Set | 保留支持原合格 R6 版本；新设／替换沿用 PDF 2.0；R2～R5、公钥、加密签名不开放 |

| 增量新建 ObjStm | 未实现；旧 compressed 成员目前独立追加 | 冻结范围不纳入，不复用旧容器写入 |
| 签名和受控更新布局 | v0.11 私有计划，限定来源／操作 | 保持原入口布局，新通用选项不能进入准备／完成流程 |
| hybrid／线性化输出 | 未提供相应布局生成器 | 暂缓；不能把保留旧结构流称为已支持生成 |

## 保留和恢复

| 能力 | 当前实现 | v0.12 冻结目标／边界 |
|---|---|---|
| 普通未知对象／字典 | 三种全量／两种增量及页面操作已按[保留矩阵](../object-preservation.md)验证私有值、共享循环、trailer 根及不可达业务对象 | 不理解私有 schema；删除检查所有保留 trailer 业务根，未知页面反向引用拒绝 |
| 来源 XRef/ObjStm | 打包模式重建已知且无活跃引用的容器；Extends、未知容器字段或外部活跃引用拒绝；其他保存模式不改旧处置 | 页面／资源导入拒绝原始结构容器；删除拒绝活跃业务图到达容器，不声称安全擦除历史 |
| Info／XMP／EmbeddedFiles | 原始 packet／payload 与非目标字段保留已验收；移除附件名称、替换 Catalog packet 不改写共享 AF／页面数据 | 不新增完整 XML 语义验证；跨文档页面导入不合并源 Catalog 元数据／附件名称树 |
| AF／AFRelationship 等 | 普通保存及页面可达图保留／重映射、共享关系有正负例和原子回滚 | 无通用语义编辑 API；未知归属无法维护时拒绝，不自动重定向私有引用 |
| Strict／Compatible | 保持原默认与语法／token 契约；新增文件结构事件、去重和不可变解析来源，与内容 diagnostics 分离 | 1024／1 MiB tracked 报告限额；懒读取后快照更新；不因诊断新增正文整行限制，不把读取成功当符合性认证 |
| xref 索引重建 | 已实现独立 RecoveredDocument；顺序 Strict 对象语法和直接 Length；单 Root／trailer／EOF | 64 MiB／100000 与 parser 限额相交，16*n+1024 扫描步数可降低；仅简单未加密单 revision／非 ObjStm，只读，无编辑／保存／签署／Document 转换 API |
| 自动修复写回 | 无专用入口 | 暂缓。新恢复来源禁止保存／增量／签署／受控编辑，不能通过 mode 或 overlay 解锁 |
| 保护／复杂历史恢复 | 原有正常读取与 v0.11 历史模型不属于恢复器 | 加密、签名、ObjStm、hybrid／多 revision 和 Root 猜测不纳入索引恢复 |
