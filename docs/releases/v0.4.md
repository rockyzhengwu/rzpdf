# v0.4 文档交互版：范围与实施顺序

状态：2026-10-14 限定范围已完成本地工程验收；用户确认修复附件限额测试后的完整工作区回归全部通过，尚未打标签或发布。可进入 v0.5 实现。本页冻结当前支持范围；未列出的交互对象不作通用支持承诺。证据来源与限制见 [v0.4 验收记录](v0.4-acceptance.md)。

逐项 API 边界见 [v0.4 支持矩阵](v0.4-support.md)。

## 交付边界

| 里程碑 | 必选范围 | 暂不承诺 |
|---|---|---|
| V04-01 导航基础 | 页目标、书签、页面链接的限定读写；引用完整性 | 任意动作、任意目录树形态 |
| V04-02 批注 | Square 矩形批注的读写、RGB 边框和可见外观 | Text、Highlight、FreeText 等其他类型及交互脚本 |
| V04-03 附件 | 文档级附件列出、添加、提取和删除；大小限额 | 附件批注、执行附件 |
| V04-04 表单 | 基础文本字段、复选框的读取、填写和外观 | XFA、签名、JavaScript、复杂字段计算 |

V04-04 限定为扁平、字段与 Widget 合一的文本字段和复选框；文本外观当前仅支持可打印 ASCII。未列出的输入结构应保留原对象或明确返回不支持，不得静默改写。

## 架构约束

- 文档级 `/Outlines`、`/Names`、`/AcroForm` 与页级 `/Annots` 分别管理；链接和 Widget 均维护页级批注引用，后续可抽取共用内部操作。
- 编辑必须在事务中完成，对目标页、父子和前后向引用做一致性检查，失败不得留下部分写入。
- 页面复制、跨文档导入和删除须单独定义交互对象的语义。在关系重映射完成前，保持明确拒绝或公开限制，不得静默丢弃。
- 保存读回、独立结构检查与独立阅读器可见性均是验收条件；仅有本库内存对象测试不足以放行。

## 当前限定实现

- 导航：扁平书签读取/追加/重命名/移除；扁平命名目标列出/设置/删除；页面链接、命名目标链接和 ASCII URI 链接读写。写入目标为本文件页面 `/Fit`；命名目标读取也可投影 `/FitH` 的页索引，但不返回视图坐标。新建 URI 链接只接受 `http`、`https`、`mailto`。
- 批注：Square 的读取/追加，写入独立的正常外观流；其他批注可与其共存，但不由该 API 管理。
- 附件：扁平 `/EmbeddedFiles` 名称树的列出/添加/提取/删除；Unicode 名称用 `/UF` 保存；删除仅解除引用，不是安全擦除。
- 表单：扁平合并 Widget 的文本字段和 Yes/Off 复选框；支持创建、读取、填写和重新生成正常外观，保留现有按下/悬停外观。保留 ReadOnly/Required/NoExport 字段标志并拒绝填写只读字段；XFA、层级字段、脚本及其他字段标志不支持。

页面复制/跨文档导入继续拒绝非空 `/Annots`。页面删除遇到目录/命名目标或非空批注时拒绝，防止悬空引用；关系感知的复制、导入和删除仍未实现。未知复杂目录树及嵌套名称树编辑会明确拒绝。

写入版本门槛：AcroForm 至少 PDF 1.2；文档级附件至少 PDF 1.4；本版的命名目标树与 Square 写入保守要求 PDF 1.4。门槛依据 [Adobe PDF Reference 1.7](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/pdfreference1.7old.pdf) 的功能版本说明；后两项是本版收窄的实现范围，不表示更早版本的所有同类结构都无效。
