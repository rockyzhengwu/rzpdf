## Known limits

Complex outline trees, nested name trees, actions/scripts, Text/Highlight/FreeText annotations, field hierarchies, Unicode text-field appearance, XFA, signatures, and relation-aware page copy/import/delete remain outside this version. Unlinking bookmarks or attachments is not secure erasure. URI actions are represented as data; the library does not open them. See the support matrix for the exact API contract.
