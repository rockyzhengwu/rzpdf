# v0.2 常用内容编辑支持矩阵（候选）

更新日期：2026-10-13。以下是拟验收的正式边界，**候选门禁完成前不表示已发布或已经验收**。基础创建/读取/页面操作沿用 [v0.1 支持矩阵](v0.1-support.md)；本表只增加内容编辑范围。验收清单见 [v0.2 盘点](v0.2.md)。

| 场景 | 拟支持范围 | 边界 |
|---|---|---|
| 定位与来源 | 同文档、同页、当前修订的文字/图片/路径来源对应 `ContentProgram`；编辑后刷新快照 | 索引和来源不是持久句柄；显示空间图片几何候选不判断遮挡/透明/裁剪 |
| 顶层文字替换 | Tj、TJ 单项与限定范围、两类引号；使用目标有效字体编码，显式普通或字距补偿模式 | 字符码边界不是 Unicode/UTF-8 偏移；不自动重排版、补字体或调整所有后续布局 |
| 顶层文字清空 | 一次 Tj/TJ/引号绘制清空字符串，保留操作符、TJ 数值和引号状态效应 | 后续文字可移动；旧流对象可能保留，不是安全擦除 |
| 字体样本 | 标准 Helvetica/WinAnsi，以及固定静态中文 TrueType/Identity-H 与现有 ToUnicode | 仅已有编码能表示的字符；复杂字体/竖排/自动子集属于 v0.3 或实验能力 |
| 顶层图片 | Image XObject 一次 Do 替换、删除、相对用户空间或显示空间仿射变换；页内资源名整体重绑 | 内联图像不支持；资源名重绑影响该页所有同名调用；尺寸匹配/可见性由调用者判断 |
| 图片样本 | RGB 图片与带 SMask 的 RGBA 固定样本；独立检查结构、位置与像素 | 其他编码、复杂裁剪与色彩管理不因此获得完整兼容承诺 |
| 顶层路径 | m/l/c/v/y/re 有限数值替换；一次绘制取消，保留挂起裁剪与邻接操作 | 当前用户空间坐标；不自动反算显示坐标或联动整条路径；不能当作脱敏 |
| 一层 Form | 非 Group Form 的一次调用内文字、Image XObject、路径编辑；重复调用和共享页通过复制后修改隔离 | 两层以上、跨调用文字范围、Group Form 和内联图像维持实验范围 |
| 事务与保存 | 多步操作同一事务；失败或 panic 回滚资源与内容；全量保存、严格重开 | 回滚后旧快照失效；保存到外部的字节不随文档事务撤回；非增量保存 |

未纳入本版：真正脱敏、自动重新排版、OCR、签名、加密、完整批注/表单、所有 PDF 字体和文件兼容性。输入限额和错误契约沿用 v0.1，操作级额度不等于全进程峰值内存上限。当前验收平台仍仅计划 macOS x86_64；仓库有 Ubuntu 工作流配置，但远端无 CI，Windows 未验证。fuzz 专项继续暂缓。
