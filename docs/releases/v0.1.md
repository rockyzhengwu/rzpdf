## 目标与边界

在明确支持范围内，可靠完成“创建/打开 → 基础提取或页面操作 → 保存 → 严格重开 → 独立工具验证”。本版不追求任意 PDF 编辑器或完整渲染引擎。

目前下列能力已在冻结支持矩阵和固定样本范围内完成验收；不因已有 API 或历史专项通过就标记正式支持。精确字体、图片格式、输入文件范围和限制在盘点阶段冻结，并写入此表或链接的支持记录。

| 分类 | 当前已有能力 / 候选范围 | 验收时必须写清的限制 |
|---|---|---|
| 新建 | 无输入源创建；尺寸、页面框、旋转；多页文字/图片/路径 | 数值/状态配对、坐标系、支持的资源类型 |
| 字体与图片 | 已有字体嵌入、中文 CID 与图片接口 | 冻结实际字体/编码/图片格式；许可与透明支持边界 |
| 读取与提取 | 已有解析、绘制顺序文字与图片提取 | 缺失映射和诊断；不承诺通用阅读顺序；原始图片与可解码图片分别列出 |
| 页面操作 | 已有复制、重排、旋转/裁剪、导入与合并/选页接口 | 逐项核对增删接口；索引、继承、共享关系、版本及输入拒绝条件 |
| 保存 | 已有保存、版本策略和严格重开路径 | 文件替换行为、失败原文件保持；加密输入的拒绝策略 |
| 实验能力 | 内容级/嵌套编辑、字体自动子集、高级横竖排和复杂绘制 | 保留现有实现与回归，不纳入 v0.1 正式承诺，后续版本专项验收 |
| 未纳入支持 | 批注/表单等完整读写、增量保存、加解密、签名、完整脱敏及符合性认证 | 解析到相关对象不等于支持编辑或完整保留其语义 |

页面导入现有非空注释、标记结构、文章归属、加密源及版本等拒绝条件须保留并公开；合并/拆分不承诺同步 Info/XMP、书签和命名目标。完整细节以接口文档为准。
