## 完整自动门禁

从仓库根运行，证据目录必须不存在；先自行准备许可允许使用的静态字体：

```sh
# 干净检出先构建：font-data/build.rs 当前会在 src 中生成被忽略文件。
# 门禁随后采集指纹；不在门禁进行中运行 rustfmt 或修改生成文件。
cargo build --workspace --locked
mkdir -p output/pdf
RZPDF_CJK_FONT=/absolute/path/NotoSansSC-static.ttf \
RZPDF_CJK_NAME=NotoSansSC-Thin \
RZPDF_CJK_CAP_HEIGHT=733 \
RZPDF_CJK_STEM_V=80 \
bash docs/check-v01.sh output/pdf/v01-candidate-001
```

名称和指标仅适用于历史记录所述实例；其他字体不能照抄。脚本不修改字体，不运行 fuzz，不覆盖现有证据目录；生成全量测试、英文/中文创建、合并/选页、独立结构/文本检查及全部页面渲染证据。保存提交号、dirty 状态、tracked patch、untracked 名称及 Rust/Cargo 内容校验和。dirty 运行只算工作区验证，不算最终候选提交验收；发布前必须在经确认的提交上复验。

`result.txt` 中 `gate_exit=0` 只表示自动检查通过；仍须目视全部 PNG、登记样本/字体许可，并确认候选提交。失败退出不能解释为跳过通过。脚本结尾核对已有源码文件未变化；最终发布还应检查没有新增或删除源文件。
