## 阅读器差异的处理

保留原始 PDF、原始 MuPDF 图、差异图与报告，不能把修正参考叫作原始完全一致。

- MuPDF 1.27 在固定样本中给直接 `sh` 使用 Background；规范规定忽略。另生成只删除该无效项的等价参考。
- 低分辨率 shading 端点离散：另用 576 dpi 像素中心对照，不提高颜色阈值。
- MuPDF 在 ca=0 的固定 knockout 样本中表现为跳过成员，丢失形状；本实现按独立 shape/opacity 公式验证，并对照 ca=1/255 的邻值样本，明确它不是等价文档。
- MuPDF 对常量 Multiply Pattern 的内部混合按隔离效果显示；本实现按 PDF 11.6.7 的非隔离模型，使用相同恒定源的直接绘制等价参考和数学值核对。
- 图像全 255 的 SMask 在原始 MuPDF 对照中得到与 ca 模型不同的结果；只删除这个全不透明 SMask 生成严格等价参考，不把快路径优化作为已证实的根因。
- ColorDodge 半透明去预乘会放大 MuPDF 的输入量化误差；分别核对不透明混合阶段、alpha 插值和公式值，不把原始差异宣传为 2 个通道单位以内。
- 字体 rasterizer 的边缘覆盖不同：先分别验证自身 mask 数值，再检查轮廓一像素邻域；字形 AA 与颜色容差分开。
- Separation/DeviceN 冻结为 tint→RGB Alternate 显示策略；保留 MuPDF 原始色料模拟结果，但另外按明确的 Alternate 策略对照，不声称复现阅读器的物理/命名油墨模型。

fuzz 暂缓；不使用 Poppler。未自动提交、推送、打标签或发布；包版本未修改。可进入 v0.9 盘点，尚未开始下一版实现。
