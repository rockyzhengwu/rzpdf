# v0.8 Pattern 专项矩阵

整版边界以 [v0.8 支持矩阵](v0.8-support.md)为准，API 见 [Pattern 指南](../patterns.md)。本文件保留 A1 的专项入口，不再把已接通的透明度和 ICC 描述为未实现。

| 场景 | 验证边界 |
|---|---|
| 平铺 | PaintType 1/2，正负步距、间隙/重叠、BBox、矩阵、默认坐标系、Form 局部资源；固定 12 页样本 |
| 绘制来源 | 路径填充/描边、图案填充文字、图案中的文字、stencil；B 操作两侧先准备再绘制 |
| 非均匀 DPI | 144/96 dpi 固定样本，3×3 premultiplied area reduction；重叠覆盖区不出现白色接缝 |
| 内部混合 | Multiply 读取实际 backdrop，而非透明页；组合门禁及非均匀 DPI 纯色像素断言 |
| Shading Pattern | Matrix、ExtGState、Background；直接 sh 忽略 Background，保留阅读器原始差异 |
| 资源 | 注册/导入、无效输入失败 revision/bytes 不变、缺失局部资源不向页级借用 |
| 累计预算 | cell 数（含空单元）、递归、重复解码工作、保留路径/载荷、离屏及 sibling shaders、失败后重试 |

首轮全量日志 `tmp/pdfs/v08-a1-workspace.log` 为 **65 组、1,219 passed，0 failed/ignored**，仅对应早期 A1 源码，不作为最终 v0.8 证据。早期 72 dpi 及非均匀门禁见 `tmp/pdfs/v08-patterns-7floexi_/report.json`；后续组/ICC/裁剪改动后必须重建并在 [最终验收](v0.8-acceptance.md)登记新报告。

失败目录和原始对照继续保留：端点离散、直接 sh Background、重叠接缝、内部混合的阅读器差异均不能宣称原始图像完全一致。优化尚不包括 tile 缓存、窄表面或任意打印设备 TilingType 策略；Skia/CMS 内部临时存储仍不是共享 OperationBudget 全覆盖。
