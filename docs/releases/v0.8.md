## 验收原则

每个正向样本同时验证解析值、绘制和严格保存重开；资源注册/导入失败不得污染页面。覆盖局部同名资源、共享页面、嵌套变换和裁剪。Skia 与 MuPDF 独立对照不能替代数值断言；不通过放宽容差或删除失败样本验收。

标准依据：[Adobe PDF Reference 1.6](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/pdfreference1.6.pdf)，图案、透明合成和颜色空间相关章节。OCR、推断型表格、自动排版、任意印刷生产流程和专色分版不在本版范围。fuzz 继续暂缓，不使用 Poppler；不自动推送、打标签或发布。
