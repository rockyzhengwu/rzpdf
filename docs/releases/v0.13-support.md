# v0.13 支持矩阵

2026-10-19，基于 `57f338f`，V13-00～08 已完成冻结范围本地验收：完整工作区 92 组／1609 项、联合 23 组／273 项、十一组必选独立门禁、间接配置补充审计及 432 页目视复核通过；9 条基线、645 输入／十三个驱动／1676 产物核对完成。[验收记录](v0.13-acceptance.md)登记真实退出与限制，不将这些计数视为全标准覆盖率。接口与数值限制见[冻结边界](v0.13-boundaries.md)，使用见[图层编写指南](../layer-authoring.md)。

| 单元 | 读取／选择 | 写入／编辑 | 明确不支持 |
|---|---|---|---|
| OCG | 延用 v0.10 注册组、名称及 Intent 选择 | 创建 View／Design、Unicode 重命名、保留私有字段 | 删除、合并、根据名称推断身份 |
| 配置 | 默认、替代、状态、选定 usage 沿用旧模型 | 简单 Name／BaseState／ON／OFF；旧 Creator／Intent 保留；带 stamp 目标 | 复杂 Usage／AS／UI／未知规则的写入；默认 OFF／Unchanged 或非 View Intent 生成 |
| OCMD | 四策略及有界 VE，VE 优先 | 创建四策略及 Group／And／Or／Not 树 | 任意现有表达式改写、未匹配 Intent 的表达式简化 |
| 新页面段 | 读取／文字／绘制沿用旧解释器 | 选定自包含文字编码段追加，局部 Properties，外层 OC | 旧／新程序内的 BI 内联图像、BX／EX；新段 MCID、MP／DP、命名 BDC 属性 |
| Form／image 调用 | 原型及内层程序照常解释 | 一个顶层 Do 包裹，其他调用和对象本体不变 | 嵌套调用入口、自身 OC／结构所有权目标、资源级 OC 覆盖 |
| 标记语义 | 旧 ActualText／Artifact／MCID 及选择规则保留 | 新段选定直接 Span／Artifact 字典；无新所有权 | 自动 ParentTree、ActualText 原子替换分割 |
| 保存 | Strict／Compatible 旧行为不改 | 三全量／两 unsigned 增量／限定 R6，保持原保护规则 | 签后普通编辑、恢复写回、静默降级保护 |
| 页面迁移 | 原限制保留 | 无新增开放 | OCProperties 跨文件迁移、图层扁平化、隐藏内容擦除 |

配置及内容快照对修改／回滚失效；ObjectHandle 仍是文件内对象地址，不新增 revision 字段。OperationBudget 是显式保守额度与部分实际 owned 分配的共享池，不是实际总分配或 RSS 计量。旧解释器、模型及原生资源的未覆盖分配保留原限额说明。

本机验证环境为 macOS x86_64，其他平台不据此声明已验证；无新依赖、CI、Poppler 或 fuzz。默认输出及 options 结构兼容，包版本／标签／发布单独处理。
