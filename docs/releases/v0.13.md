## 冻结范围

### A 图层和配置

- 创建间接 OCG，支持 Unicode 名称与明确 View／Design Intent；同名不等于同一身份。
- 修改已有已注册 OCG 的名称；创建和编辑默认配置及替代配置的名称、BaseState、ON／OFF。
- 创建选定 OCMD：AnyOn／AllOn／AnyOff／AllOff，以及有界 And／Or／Not 表达式；沿用现有求值语义，不添加另一套求值器。
- OCG／OCMD 只接受本文件有效对象句柄，配置目标另带文档 stamp 和位置；ObjectHandle 本身不携带 revision。未注册成员、重复或冲突状态、循环、非法表达式和超限均失败。
- 不生成复杂 Usage／AS、Order、RBGroups、Locked 编辑模型。已有复杂／未知配置的状态写入拒绝；组名称可按独立字段更新。现有 Creator／Intent 保留，但默认配置必须为 View Intent；不从快照重建整份 OCProperties。

### B 显式内容绑定

- 对新建且已验证、平衡的页面内容段生成 `/OC ... BDC`／`EMC` 和页面 Properties 绑定。不得用整页包裹接口任意拼接未经验证的操作符片段。
- 为明确选定的顶层 Form／image 调用建立 OC 绑定；使用单次 Do 的 BDC／EMC 包裹，不修改或克隆共享 XObject，不能为改一个调用污染所有页面。无法证明完整性的输入拒绝，不改成全局绑定。
- 绑定兼容嵌套标记内容；保留 MCID／ActualText／Artifact、资源继承及内容事件来源。未知扩展、跨流不平衡或无法确定边界拒绝。
- 无图层选择的旧 API 行为不变；显式选择继续用于显示与文本筛选。不提供删除隐藏内容、图层扁平化、脱敏或安全擦除。

绑定的精确公开签名和允许内容语法见[公共边界](v0.13-boundaries.md)；可运行调用见[使用指南](../layer-authoring.md)和 `v013_layers` 示例，不将原盘点草案当作已发布 API。

## 架构边界

1. 将写入逻辑放入独立 `document/optional_content_edit.rs`，保留现有只读模型／求值入口；共享校验代码而非复制整个读取器。
2. 复用 `DocumentIdentity`、`ObjectHandle` 和 `DocumentStamp`。写入使用内部预检计划与既有事务；回滚后按既有规则重新获取快照，不能承诺旧快照复活。
3. 修改采用 copy-on-write，局部补丁保留不相关字典键及引用共享；资源名冲突显式分配，不按展示名称合并对象。
4. 复用权限、版本、来源与签名保护。可选内容要求适用版本，VE 版本单独检查；低版本明确升级或拒绝，不静默改 header。RecoveredDocument 不获得写 API；签后受控入口不扩大授权。
5. 对组数、配置数、表达式节点／深度、内容字节和遍历工作量定限额；新增临时计划与载荷纳入 OperationBudget，记录既有未覆盖分配，不把 tracked 峰值当 RSS。
6. 不改 SaveOptions 等既有结构的必填字段，不改变默认 writer 布局。新接口按现有 owned Document 转发风格提供一致入口。

## 独立样本与运行门禁

正例至少覆盖默认与两套替代配置、同名不同组、Unicode、四类成员策略、嵌套 VE、共享 Form／image、继承与显式空资源、嵌套 ActualText／Artifact。负例包括外国句柄、非法状态、未知相关配置、资源别名污染、不平衡内容、过低版本、签名和恢复来源，以及限额恰好不足和同池有效重试。

外部生产者采用已验证的 pikepdf 和 MuPDF create 原始合成配方，两类来源不能由同一 qpdf 后端冒充独立实现。qpdf／pikepdf 检查结构与对象投影，MuPDF 检查输出默认可见结果；替代配置使用独立期望文档与显式选择，不能比较不同配置。固定几何同时检查 Skia／MuPDF，文本另行检查，冻结容差并逐页目视复核；间接配置／旧别名补充配方见[测试说明](../testing.md)。

先跑定向和阶段联合，再冻结一次源码完成全量与外部门禁。源码变化后按影响复验，不复用旧截图。编译／启动／测试正文分别记录；长测不以 ignore 放行。所有产物新建目录，记录生成命令、许可、工具版本和 hash；不用 Poppler、不跑 fuzz、不安装工具或创建远端 CI。其他平台仅按实际运行结果登记，不延用 macOS 结论。

## 标准与关联资料

语义入口为 ISO 32000 可选内容 8.11，内容绑定同时核对标记内容规则；PDF 1.7 与 PDF 2.0 差异逐项登记，而不是将两版规则混用。标准入口：[PDF Association 第 8 章勘误](https://pdf-issues.pdfa.org/32000-2-2020/clause08.html)。现有语义及保留边界见[可选内容指南](../optional-content.md)、[跨版本覆盖索引](../pdf-standard-coverage.md)和[v0.12 验收](v0.12-acceptance.md)。
