# v0.10 支持矩阵

状态：V10-01～09 的限定范围已完成本地验收，三个阶段和横向门禁全部关闭。最终源码完整工作区 80 组、1,453 项，206 项联合回归、七组独立门禁及图层像素/目视对照通过。范围见[计划](v0.10.md)，证据见[验收记录](v0.10-acceptance.md)；不将限定模型等同于完整 Tagged PDF/PDF-UA 支持。

| 能力 | 状态 | 边界 |
|---|---|---|
| 结构层级快照 | 首次限定切片已定向验证 | 间接节点、原始 K 顺序、P/K、RoleMap 关联端点及合法环、页面句柄、元数据；不校验内容/ParentTree；无树返回 None |
| MCID/MCR/OBJR/ParentTree | 限定只读验证 | `structure_associations()` 扫描实际页面及调用 Form，支持 Properties、整数 K/MCR/Stm、批注及 XObject OBJR、null 槽和双向索引；与 PDF 2.0 命名空间/本地属性模型集成，但不证明完整 PDF 2.0 Tagged 内容限制合规 |
| 共享 Form 与 whole-XObject | 限定验证 | MCID 按域隔离，重复调用计入累计预算；Form 缺省 Resources 回退到页面，空字典不继承；跨页资源导致 MCID 集变化拒绝；whole-XObject 每使用页需 OBJR |
| 外观流 MCR 与 StmOwn | 不支持 | 归属验证明确拒绝；ParentTree 引用支持子集之外的所有者也拒绝，不宣称输入必然不符合规范 |
| ActualText | V10-03 限定范围已验收 | `extract_marked_text()` 支持 Span/Artifact、Properties、Unicode/空值及跨操作替代；结构接口支持元素 ActualText；保留替代来源，不伪造字符码/坐标，不计算 Lang 继承或 Alt 替代 |
| Artifact 与结构顺序 | V10-03 限定范围已验收 | 过滤 Artifact 及后代；`extract_text_structure_order()` 按 K 而非绘制顺序，无树返回 None；域/MCID 关联，不猜测无标签顺序；多实例 Form、跨所有者原子替代拒绝，未关联单位和未提取 OBJR 明确计数 |
| 显式节点编辑 | V10-04 限定范围已验证 | 增改、混合 K 移动、空节点删除/子项提升；同步 P、显式 Pg、ParentTree；不删除正文/递归删除内容子树，已有 Form MCR/OBJR 可保留及转移所有者 |
| 页面标记及 MCID 分配 | V10-04 限定范围已验证 | 当前文档快照、单原始内容流的完整未标记操作范围；Span BDC/EMC、可选 ActualText、页面 MCID/StructParents/NextKey 和 MCR；新流隔离共享来源，不写 Form 内部标记；不设置 MarkInfo/Marked 或证明全部正文已标记 |
| RoleMap 与局部属性写入 | V10-04 限定范围已验证 | 根 RoleMap 设置/移除及环拒绝；直接 A 数据与当前 R 修订，保留 NS/C/ClassMap；NSO、引用/流和命名空间/ClassMap 定义写入不提供；未知结构及反向扩展拒绝；要求 PDF 1.4+、修改权限及无签名来源 |
| 页面复制/导入/选页/合并 | V10-05 限定范围已定向验证 | 自动投影选中 K 分支和祖先，维护 P/Pg/Stm/Obj；新 ParentTree 键、MCID 域隔离和 null 槽；同文档结构复制隔离资源图；不拆分原子 ActualText，未知扩展拒绝 |
| 删除/重排与共享 Form | V10-05 限定范围已定向验证 | 删除裁剪页内容和空分支、维护反向键；唯一候选页可重绑 Form Pg，多候选拒绝；重排保持声明 K；导航重定向独立，不把删页当安全擦除 |
| 正文编辑保护 | V10-05 限定范围已定向验证 | 共用快照提交前后验证 MCID/MCR/OBJR；页面 MCID 内普通 Form 可隔离编辑；结构 Form 域无法维护时拒绝并回滚；不自动改 ActualText；原始内容/对象更新仍是低层构造工具 |
| OBJR 与根定义冲突 | V10-05 限定范围已定向验证 | 批注/Widget 的已验证页面关系和 AP 保留；普通字段编辑保护不放宽；RoleMap/ClassMap 名冲突、定义捕获双方未映射角色/未定义类、间接/不透明定义伪等价和跨文档同 URI 命名空间拒绝，不隐式重命名 |
| PDF 2.0 命名空间 | V10-02 限定范围已验证 | 有效版本 2.0；NS/Namespaces、RoleMapNS 名称/二元目标、跨命名空间端点及循环/缺引用检查；NS 不继承，Schema 不联网；同 URI 多字典明确拒绝，不验证标准角色词表或 Tagged 包含规则 |
| ClassMap/A/C 与修订 | V10-02 本地关联已验证 | 直接属性按 owner/key 覆盖类属性；PDF 2.0 后项优先，PDF 1.x 重复项报告歧义；未知类为空，修订号保留并检查；NSO 按 URI 区分所有者，未知流返回 Opaque；不做布局继承/默认值或全属性值域验证 |
| OCG/OCMD 与配置 | 限定范围已验收 | 文档限定模型/快照，默认/替代配置、BaseState/ON/OFF、显式 View/Print、四种成员策略、有界 VE、匹配 AS 状态类别、临时覆盖与缓存区分；循环/未知规则拒绝，详见[指南](../optional-content.md) |
| 图层渲染/提取 | 限定范围已验收 | 显式接口处理 named BDC Properties、Form/image/批注 OC 和支持的透明组；隐藏仍执行状态/限额，来源位置不变；原有接口契约不静默改变，不把隐藏当删除 |
| 图层边界与页面迁移 | 保守拒绝 | OCProperties 页面迁移、OCG/OCMD 或带 OC 的 XObject 导入仍拒绝；不提供图层作者/扁平化/动作运行时；软蒙版 G 自身 OC、OCMD/VE 不匹配 Intent、环境相关 AS 类别及结构元素 ActualText 的图层分割明确拒绝 |
| 完整回归和独立验收 | 整版限定范围通过 | 最终完整工作区 80 组、1,453 项，14 组、206 项联合回归，七组独立门禁退出 0；三配置图层像素/目视对照通过，457 个源码输入前后指纹与列表一致，见[验收记录](v0.10-acceptance.md) |

本版不提供 PDF/UA 符合性承诺、OCR、语义推断、自动排版或动作执行。未改包版本，未提交、推送、打标签或发布。
