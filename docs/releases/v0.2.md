# v0.2 常用内容编辑：范围、盘点与验收清单

盘点日期：2026-10-13；最初代码基线：`0a354e3`。**v0.2 的 V02-01～07 已在候选 `89b98a3` 全部通过，工程验收完成，尚未打标签或发布。** 本文保留开工前盘点；最终证据见 [验收记录](v0.2-acceptance.md)，正式边界见 [支持矩阵](v0.2-support.md)。版本总范围见 [路线图](../../ROADMAP.md)，详细接口和历史专项证据见 [内容编辑](../content-editing.md)。

## 已验收的交付边界

- **必选：顶层页面 Contents 中有来源的编辑。** 使用当前文档、当前页面、当前修订的 `ContentProgram` 与绘制来源；支持 Tj、TJ 字符串/范围、两类引号操作的文字替换与清空；一次 Image XObject 绘制的替换、移动/仿射变换及删除；m/l/c/v/y/re 路径数值修改与绘制取消。图片资源名整体重绑单列，说明它会影响该页对同一名称的所有调用。
- **限定文字字体：** 已嵌入或已注册、可以确定有效字体与字符码映射的字体。验收样本至少包含标准 Helvetica/WinAnsi 和项目 v0.1 已支持的固定静态中文 TrueType/Identity-H；缺字或无法证明编码时明确报错。文字位置保留作为明确选择的补偿接口验收，不默认重新排版。
- **限定嵌套：** 一层非 Group Form 内、一次可定位调用的文字/图片/路径编辑已验收，覆盖重复调用与共享页。两层、跨不同调用的文字范围与自动字体子集，只有独立样本矩阵补齐后才升为正式支持。
- **通用承诺：** 未选中操作及共享页面保持；错误或 panic 触发的事务回滚不留下局部资源/内容更新；保存后严格重开，独立工具检查结构、文字及画面。成功修改或回滚后重新获取来源快照。
- **本期不承诺：** 自动重排版、字形命中/可见性命中、任意字体与竖排、内联图片、Group Form、完整透明/色彩管理、真正脱敏、可达性对象清理、增量保存、fuzz。水印/覆盖内容保留现有实验接口，另行验收。删除绘制不等于旧字节或资源被安全清除。

上述边界是已验收的限定范围，不按现存 API 数量扩大承诺。

## v0.2 必选验收清单

以下清单按本版限定范围执行。勾选依据是**同一候选源码**的自动门禁、独立检查和视觉证据；已有专项只作为基线。

- [x] V02-01 来源契约：文字/图片/路径从同页同修订报告选中；修改后刷新快照，过期/错页/外文档来源拒绝且不误改。
- [x] V02-02 文字：Helvetica 的 Tj/TJ/引号替换和清空，以及固定静态中文 TrueType/Identity-H 的局部替换；独立提取精确文字与后缀坐标，缺字拒绝。
- [x] V02-03 图片：一次 Do 替换、显示空间平移或相对变换、删除；另验资源名整体重绑与透明图片固定样本，区分影响范围。
- [x] V02-04 路径：m/l/c/v/y/re 数值替换和一次绘制取消；独立渲染覆盖矩形、曲线或描边及相邻/裁剪保持。
- [x] V02-05 限定 Form：一层非 Group Form 内文字、图片、路径的来源编辑；重复调用与共享页隔离、失败回滚、独立结构/画面对照。
- [x] V02-06 原子性：多步文字/图片/路径编辑成功与错误/panic回滚；资源、内容流、共享页和保存重开结果均核对。
- [x] V02-07 候选门禁：完整工作区锁定依赖回归与 [v0.2 自动门禁](../check-v02.sh) 退出0，记录版本、哈希、样本许可、视觉检查、支持矩阵和已知限制。

受控独立生产者样本 `pdf/tests/fixtures/v01/mupdf.pdf` 已有来源/许可登记；v0.2 使用它对照三页原稿/编辑稿。新 [来源驱动编辑示例](../../pdf/examples/edit_external_v02.rs) 与 [独立检查脚本](../check-v02-external-example.sh) 覆盖 Helvetica 文字前缀、一次带 SMask 的 RGBA 图片绘制替换及显示空间平移、矩形数值修改、共享原页保持。它仅覆盖上述清单的一个组合，不替代 TJ、曲线或 Form 子项。

新 [一层 Form 编辑示例](../../pdf/examples/edit_form_v02.rs) 与 [独立检查脚本](../check-v02-form-example.sh) 使用项目自编两页样本：同一 Form 在每页重复调用，仅编辑第一页第一调用的 Helvetica 文字、图片与矩形。qpdf 检查结构，MuPDF 检查文本/绘制事件和实际 RGB 像素；第二调用及共享页保留。它不代表 Group Form、嵌套两层或任意复杂透明与字体支持。

新 [四类文字操作示例](../../pdf/examples/edit_text_operators_v02.rs) 与 [独立检查脚本](../check-v02-text-operators.sh) 用绘制来源逐次修改 Tj、TJ、单引号、双引号操作；独立核对逐行文字及每行起点。中文固定样本另由 [位置检查脚本](../check-v02-cjk-edit.sh) 对照编辑前后字符坐标和未编辑页渲染。两者仍是限定字体、限定布局的受控样本。

## 建议实施顺序与退出条件

1. **定支持矩阵和样本。** 给每类操作列出页面级与一层 Form 的正式/实验边界，登记独立来源、许可、预期编辑结果和输出。复用 v0.1 的固定静态中文字体及已有编辑示例；新样本明确标注生成者，不冒称真实业务样本。
2. **补公共工作流。** 用来源报告选择目标，执行编辑，刷新快照，严格保存重开；修正盘点中暴露的 API/行为问题。优先保证顶层必选场景，不为高级子集功能重做已有实现。
3. **补缺失的组合回归。** 覆盖相邻内容、重复调用、共享页、过期/错页来源、字体缺字、资源注册失败、事务错误/panic 与预算拒绝；只有实际缺失的场景才新增测试。
4. **独立验收。** 在同一候选提交运行相关专项和完整工作区回归；用 qpdf 检查结构，用 MuPDF 检查文字、位置和图像，再渲染固定页面逐页查看或与已审阅基线逐像素比较。记录工具版本、命令、样本来源及失败结果。当前没有远端 CI，不能把本地结果写成多平台通过。
5. **版本交接。** 全部必选项通过后发布支持矩阵、已知限制、示例与变更记录；正式标签/对外发布单独处理。
