## Advisory review and baseline remediation

Cargo metadata and exact-version OSV batch queries are archived under ignored
`tmp/pdfs/v05-dependencies*.json` and `v05-osv-audit*.json`. Primary RustSec DB
snapshot: `6aed84668c23d7f535077a9fe918bf1fa0f6a5bc`.

The initial full-workspace query covered 136 registry packages. No newly selected
security/CMS dependency was flagged. It did find pre-existing dependencies:

- quick-xml 0.39.2: RUSTSEC-2026-0194 / 0195; updated to 0.41.0 (patched range).
- tar 0.4.44, a Skia build dependency: known extraction advisories; updated locked
  dependency to 0.4.46. This is not a general archive extraction feature added
  to the PDF API.
- core2 0.4.0: RUSTSEC-2026-0105, unmaintained/yanked. Updating bitstream-io
  4.9.0 to 4.10.0 replaces it with maintained no_std_io2 0.9.4.

ring 0.17.14 is above the 0.17.12 fixed range for RUSTSEC-2025-0009 and outside
the <0.17 unmaintained range. RUSTSEC-2025-0007 was withdrawn. sha2 0.10.9 is
outside the buggy 0.9.7 range of RUSTSEC-2021-0100. No RustCrypto RSA private
operation dependency was added. Consult current advisories again before release;
absence of a database finding does not prove absence of vulnerabilities.

Actual final query, build and regression outcomes belong in the
[acceptance record](v0.5-acceptance.md); do not infer completion from this review.
After the three baseline remediations, the exact-version OSV query covered 135
registry packages and returned an empty findings list. This is a dated database
result, not a claim that every dependency is vulnerability-free.
