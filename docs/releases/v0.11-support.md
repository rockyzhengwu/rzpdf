# v0.11 支持矩阵

状态：2026-10-17，V11-00～13 已完成限定范围本地验收。最终完整工作区 85 组、1,501 项，联合 156 项，四组独立门禁共 120 案例、八组精确像素及目视复核通过，609 项冻结输入前后内容和列表一致。范围见[安全矩阵](v0.11-security-matrix.md)，证据见[验收记录](v0.11-acceptance.md)，任务见[计划](v0.11.md)。不等于完整 PDF/PAdES 合规或已发布版本。

| 能力 | 当前状态 | 边界 |
|---|---|---|
| R6 加密增量保存 | 限定范围已验收 | 严格不可变、未签名字节输入；直接或间接 Encrypt，原保护参数与第一文件 ID 不变，非空追加更新第二 ID；只对变更输出对象加密，源前缀保留 |
| 版本与输入布局 | 限定验证 | PDF 2.0 或 1.7 ADBE extension level 8；classic/xref/ObjStm 输入由现有解析器处理，变更成员以独立对象追加；不新增 ObjStm/xref stream 输出布局，不改写源结构容器 |
| metadata / Crypt / 附件 | 限定验证 | 沿用现有 EncryptMetadata、Identity 与命名 Crypt 处理；输出仍受相应公开例外影响；不是隐去旧内容或认证加密 |
| 权限与保护身份 | 保持拒绝保护 | 不修改 user/owner、modify/fill_forms 等既有授权；Encrypt/ID 的低层篡改以及加密字典更新/删除拒绝，保护替换走显式全量保存 |
| 失败/重试/多轮 | 限定范围已验收 | 三轮源前缀与严格重开、无操作精确返回原字节、事务/外层 panic、共享预算、输出限额和 writer 失败；密文随机化，不保证非空重复保存字节相同 |
| 历史 Standard handler 读取 | 未纳入 | R2/R3/R4/R5 仍明确拒绝；R4/AESV2 有独立拒绝负例；不新增弱算法输出 |
| 历史签名模型 | 限定范围已验收 | 真实 xref/Prev、EOF、签署时字段与 ByteRange/Contents；报告历史签名字典被替换/删除的状态；混合/加密历史及压缩签名字典明确拒绝 |
| 公开历史验签、RSA-PSS/ECDSA | 限定范围已验收 | `signature_reports` 保留 NotPerformed；`verify_signatures` 区分密码学结果，无信任/授权结论；限定 SHA-256/RSA，PDF 2.0 的 PSS salt32/MGF1-SHA256 和命名 P-256；详见[指南](../signature-verification.md) |
| 多签追加 | 限定范围已验收 | `prepare_additional_signature`：严格不可变、未加密 PDF 2.0，无历史 MDP/Lock/SV/AA/XFA 等声明；间接 AcroForm、至多 256 个扁平已签/文本/复选框 Widget，总签名至多 16；只添加新不可见审批字段，全部旧签有效且最新签覆盖完整来源；详见[指南](../advanced-saving.md#additional-approval-signatures) |
| 层级签名字段与可见外观 | 限定范围已验收 | `add_signature_field` 创建层级/多 Widget 空字段；`prepare_field_signature` 向唯一既有空字段签署，FT/flags 可继承；显式文字、字体/尺寸/对齐，无自动布局；AP 自有资源，复用源嵌入字体；None 保留原 AP/BBox/Matrix |
| DocMDP/FieldMDP 读取 | 限定范围已验收 | 签署版本绑定；唯一第一认证签名、P=1/2/3 与省略 P=2，V 名称 /1.2；FieldMDP All/Include/Exclude 按当时字段身份与组后代展开；未知 transform、字段集合、冲突 Lock 均拒绝写入 |
| 受控签后修改 | 限定范围已验收 | 既有 Tx/checkbox 填值及 AP 更新、既有空字段签署、新增 Square 批注；P=1 拒绝，P=2 禁止批注，P=3 支持该批注子集，再与字段锁相交；普通编辑/全量/普通增量保存仍拒绝；详见[指南](../signed-workflows.md) |
| 实际变化与完成复核 | 限定范围已验收 | `signature_modifications` 独立报告 Allowed/Forbidden/Unsupported；比较对象、所有权、字段/Widget、AP/字体、trailer、页面与 Annots；完成时重开验证全部旧签、来源前缀和计划变化；不把仅保留原字节当授权 |
| 修改约束未开放组合 | 明确拒绝 | 加密签名、模板实例化、signed radio/choice/密码/comb/rich text 更新、新建字段于认证来源、批注更新/删除/其他类型、新 Lock/SV 写入、未知扩展关系；不是全体标准允许操作的实现 |
| 加密签名、PAdES/LTV/在线信任 | 不支持 | 不提供私钥管理、网络撤销/TSA 或信任背书 |

阶段 A/B/C 和横向门禁均已按上述范围结束；未开放的标准组合仍明确拒绝，不以测试数量代替标准覆盖率。实际平台仅 macOS x86_64；未改包版本、提交、推送或发布，未安装依赖或 Poppler，未运行 fuzz。可盘点 v0.12，不自动开工。
