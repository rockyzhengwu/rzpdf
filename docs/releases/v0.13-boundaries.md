# v0.13 接口与支持边界

2026-10-19，基线 `57f338f`。V13-00 的首版 profile 在此固定；实现及测试状态另见[验收记录](v0.13-acceptance.md)。标准语义采用 PDF 1.7 可选内容及标记内容，PDF 2.0 输出继续遵守已有 writer 检查；[勘误入口](https://pdf-issues.pdfa.org/32000-2-2020/clause08.html)不代替完整规范。这里的生成子集不等于读取器接受的所有组合。

生成规则另对照 Adobe 发布的 [ISO 32000-1:2008](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/PDF32000_2008.pdf) 8.11.4.3／Table 101；本地参考 SHA-256 为 `9de0ca9e8570d6209e8bd48a355be8eb6ec376acfc3fc3ae97cd8730351417ff`，只作内部参考，不纳入仓库分发。默认配置 ON／View 的生成检查与旧 Compatible 读取是独立契约。

## 公共入口

新类型在 `document::optional_content_edit`，方法位于 `PdfDocument<R>`，owned `Document` 通过现有 Deref 使用，不增加重复转发实现。

| 方法 | 行为 |
|---|---|
| `create_layer(label, intent, budget)` | 创建间接 OCG 并注册；View／Design Intent，返回本文件 ObjectHandle |
| `rename_layer(group, label, budget)` | 改已注册 OCG 的名称，保留其其他字段 |
| `layer_configuration_target(index)` | None 为默认、Some 为替代索引；目标包含私有文档 stamp |
| `write_layer_configuration(target, configuration, budget)` | target=None 追加替代；Some 目标更新 Name／BaseState／ON／OFF，未提供 Name 表示移除名称 |
| `create_layer_membership(groups, policy, expression, budget)` | 新建间接 OCMD；四策略及选定 VE，不修改现有表达式 |
| `append_layer_content(page, membership, source, budget)` | 追加经过验证的新内容段，以 q、OC BDC、EMC、Q 包裹 |
| `bind_layer_xobject_call(page, expected, operation, membership, budget)` | 为一个顶层命名 Do 增加 OC BDC／EMC，保留其他调用和 XObject 本体 |

`LayerConfiguration` 为明确的状态输入，`LayerExpression` 为 Group／And／Or／Not。组名、配置名不是身份；ObjectHandle 不承诺 revision 保护，配置目标及内容快照检查确切文档和 revision。编辑后重新获取配置目标和内容程序。

## 输入与状态约束

- OCG 至少 PDF 1.5，带 VE 的成员字典至少 1.6。低版本先通过既有机制明确升级并重开；编辑不静默升版。默认配置要求 BaseState ON、Intent View（可省略），不生成 OFF／Unchanged；替代配置允许这两种状态。既有兼容读取不因此收紧。
- 状态数组要求已注册间接 OCG、无重复／冲突；OCMD 要求非空、不重复组列表。VE 根不能只是 Group，And／Or 至少两个子节点，Not 恰好一个。所有分支均校验。
- 已有配置仅接受 Name／Creator／BaseState／ON／OFF／Intent 字段；保留 Intent／Creator。涉及 Usage／AS、UI 约束或未知扩展的配置写入拒绝。组重命名可独立保留私有字段。
- 新内容段和旧页面程序要求 UTF-8 可表示的源编码及完整的 q／Q、BT／ET、BMC／BDC／EMC、路径与 clipping 边界；允许普通编码文字和路径，不支持任何 BI 内联图像（包括 ASCII 编码载荷）及 BX／EX。已有页面包含这些项时也拒绝本版高层绑定／追加，不影响其他原有内联图像 API。
- 新段的 BDC 仅允许直接 Span／Artifact 属性字典，不允许 MP／DP 点，不能新建 MCID 或用命名属性绕过所有权检查。已有页面标记及外层 OC 保留；结构变更仍由原内容提交器检查。
- 选中的顶层 Do 必须引用 Form／image，带自身 OC、StructParent／StructParents 的目标拒绝。通过标记内容隔离调用，不克隆对象，因此不引入资源引用、BBox、矩阵、mask 或结构副本。原 XObject 不变；嵌套目标不提供入口。
- 增加图层不使其内容成为红删／安全擦除；隐藏程序仍解释并消耗工作量。追加段需要完整解释成功，否则事务回滚。

## 数值限额与预算

组上限 1024，替代配置上限 256，表达式节点上限 4096，表达式深度小于 64，新段／旧程序验证载荷分别不超过 1 MiB，页面 Properties 条目不超过 4096。相应限制与既有 max_objects、max_depth、max_content_operations、max_raw_stream_bytes、max_decoded_bytes 相交；字符串沿用 token／字符限额。

每个写入口要求显式共享 OperationBudget。内部新表／小型构造采用保守 2 MiB scratch reservation；名称／内容额外保留 16 倍输入字节的临时额度。预算化 owned 字典、页面定位、内容程序及事务快照单独计费；即便是小编辑也可能因不足 2 MiB 而拒绝，不能把该峰值当作实际分配或 RSS。嵌套事务使用同一个池。

旧只读模型／可见性求值、最终 DisplayList 解释、源缓存、工作 store 增长和原生资源仍不受这份 tracked reservation 完整覆盖；解析和内容工作限额继续适用。不宣称所有分配或 RSS 有界。调用者拥有的输入／预期快照不重复计费。

## 保存和权限

原 options、默认布局、Strict／Compatible、普通保存与增量行为不变。新变更可进入三种全量布局和两种 unsigned 增量，保护组合沿用限定 R6。签名来源检查先使用调用者预算；禁止从签名或只读恢复来源获得普通编辑授权，受控签后入口未扩展。

失败前预检不变更源内容；已进入事务的失败会回滚图和载荷，但按旧规则使旧快照失效。文件保存原子策略不变。示例程序新建输出目录／文件，后续保存失败可能留下先前成功的样本，不提供整目录事务。

组删除／合并、图层页面迁移、扁平化、OCProperties 整体重建、动作运行、复杂 Usage／UI 编辑、自动语义布局和新 MCID 所有权不在本版。现有迁移／签名／恢复拒绝保持。
