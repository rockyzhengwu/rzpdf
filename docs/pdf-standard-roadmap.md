## 标准依据和支持口径

以 [ISO 32000-2:2020](https://pdfa.org/resource/iso-32000-2) 和 [PDF Association 发布的勘误](https://pdf-issues.pdfa.org/32000-2-2020/) 为主要依据，并为 PDF 1.7 及更早输入保留明确的版本兼容矩阵。规范快照、适用章节、勘误及扩展编号在每版开工时登记；不能把 PDF 2.0 的规则无条件套到所有旧文件。

“按规范实现”表示声明支持的场景符合相应规则，不表示所有可选、旧版或行业扩展均已实现。以“标准条目 × 版本 × 读/写/渲染/编辑”记录覆盖：

| 维度 | 验收含义 |
|---|---|
| 读取 | 能解析并暴露正确类型、值、引用关系和诊断 |
| 写入 | 能生成符合所选 PDF 版本的结构，并由独立工具读回 |
| 渲染 | 正确解释已声明的绘制语义，不以结构检查代替像素验证 |
| 编辑 | 修改后相关引用、外观和作用域正确；共享对象隔离、失败回滚 |
| 原样保留 | 能保存未解释对象；不冒称已经理解或支持其执行语义 |

各单元格标为已验收、部分支持、计划实现、明确不支持或不适用，并链接证据。TODO 的长期父项未勾选不等于对应能力完全不存在。

## 核心与应用层边界

| 放入 PDF 核心或渲染层 | 放入上层应用或独立服务 |
|---|---|
| 字符码、Unicode 映射、GID、字形位置、文字状态和来源位置 | OCR、翻译、复杂文字 shaping、自动字体选择及段落排版 |
| 读取、创建和维护已有逻辑结构树及显式阅读顺序 | 从无标记页面推断段落、多栏、表格和阅读顺序 |
| 图像流、过滤器、颜色、蒙版及绘制事件 | 图像内容识别、版面分类、业务信息抽取 |
| 页面、表单、批注、目标和动作的标准结构与外观 | 编辑器 UI、点击行为、网络访问、脚本运行环境和业务计算 |
| ByteRange、CMS 完整性、签名字段和变更约束结构 | 私钥管理、证书信任策略、在线撤销/时间戳服务 |

已有 Tagged PDF 的 Table、Heading 等显式结构属于标准解释能力；推断未标记页面的表格不属于同一功能。参见 [Tagged PDF 说明](https://pdfa.org/resource/tagged-pdf-q-a/)。上层可把 OCR 或排版结果交给核心写入文字、字体、ToUnicode 和结构标签，核心不负责推断结果的真实性。

保留 `pdf`、`render`、`font-data` 三个 crate：核心不反向依赖 OCR、模型服务、编辑器 UI 或 Skia。解码、色彩转换和密码学可通过经过审查的依赖/后端实现；接口必须暴露能力、错误和预算边界。没有实际依赖隔离需求时不提前拆出大量 crate。

## v0.6 内容流与图像基础

标准入口：第 7 章 Syntax 和第 8 章 Graphics；具体图像、过滤器和内容流条目在开工矩阵登记。

分为 A 内联图像及既有解码器、B JPX、C JBIG2；详细任务见 [V06-00～08](releases/v0.6.md)。

- 标准图像字典和 BI/ID/EI 内容流对象的有界读取，压缩数据中的 EI 不得误判为结束。
- 统一 Image XObject 与内联图像的参数解析、解码、绘制、提取和来源定位。
- 审查并接入进程内 JPX/JBIG2 后端；支持的容器、颜色、Globals、蒙版组合逐项冻结。
- 保留已有编码流；修改逻辑像素时显式重新编码。第一期不要求 JPX/JBIG2 编码器。

退出条件：逐像素/文字位置独立对照、内联图像前后操作不丢失、保存重开、替换/删除及共享隔离、限额失败与回滚。单纯增加两个过滤器函数不能作为整版完成。

## v0.7 字体与文字解释

标准入口：第 9 章 Text，复用第 7/8 章的流和资源解释。

分为 A Type3、B 字符映射和嵌入字体兼容、C 字形运行与读写闭环。

- Type3 字形程序、字体矩阵、度量、局部资源和 d0/d1 语义；递归及资源预算与页面解释器共用。
- 扩充 Simple/Type0/CID、Encoding/Differences、ToUnicode 多标量/代理对、竖排和缺失映射的固定矩阵；修复已知真实文件映射缺口。
- 盘点现有 Type1/CFF/TrueType/OpenType 路径，按实际 PDF 字体类型补齐读取和绘制，不能把“没有子集器”等同于“不能渲染字体”。
- 提供有明确编码/GID/位置契约的字形运行写入；上层 shaping 结果可以输入，核心不内置语言布局或自动字体搜索。
- 扩大现有静态 TrueType 子集验收；不要求本版自行实现所有 OpenType 布局、变量字体或彩色字体子集。

退出条件：独立核对 Unicode、CID/GID、宽度、竖排原点及字体轮廓；真实文件和独立生产者样本保存前后可对照；缺字和缺失映射显式报告，不用替代字体掩盖失败。

## v0.8 图形颜色与透明度

标准入口：第 8 章 Graphics 和第 10 章 Rendering。

分为 A Pattern 与渐变、B 透明度、C 颜色管理。

- 平铺 Pattern 的着色/非着色模式、局部资源、矩阵、步距和裁剪；Shading Pattern 独立于直接 sh 操作验收。
- 保留已有 Shading Type1～6 实现，补齐声明支持的曲面/边界/重叠场景；新增 Type7。不能按历史未勾选项从零重写已有能力。
- 透明 Form Group 的隔离/挖空、SoftMask 的 Alpha/Luminosity、混合模式与文字绘制/裁剪状态闭环。
- ICCBased、Lab、Separation/DeviceN 及输出颜色转换；色彩后端、目标配置和容差显式选择，不把 Alternate 回退等同于完整色彩管理。
- 按所支持的嵌套 Form/资源/变换组合扩大解释范围；超出范围仍明确拒绝。

退出条件：独立渲染加解析值/几何断言，覆盖背景、裁剪、资源作用域和共享页；分别冻结色彩与抗锯齿容差。复杂 Type6/7 和颜色管理允许独立里程碑，但不可省略必选门禁。

## v0.9 文档交互与对象关系

标准入口：第 12 章 Interactive features，结合第 7 章的树和对象引用规则。

分为 A 导航、B 批注、C AcroForm 与页面关系。该版已按[冻结清单](releases/v0.9.md)限定范围完成，以下为范围摘要，不代表任意变体均受支持。

- 层级 Outline、平衡 Name Tree、常用目标视图、页标签；链接与命名目标修改/删除。
- Text、FreeText、Line、Circle、Polygon/PolyLine、文本标记、Ink、Stamp/Popup 和 FileAttachment 等常用批注分批提供读、增、改、删与 Appearance。Redact 的结构/外观与真正应用脱敏分开处理。批注集合开工时冻结。
- AcroForm 层级与继承、分离 Widget、文本/复选/单选/Choice/PushButton 的结构和外观；中文字段用已验证的字体和编码生成外观。
- 删除、复制、导入和重排页面时，维护已支持的批注、字段、目标和书签关系；无法迁移的关系在事务前拒绝。
- 动作提供类型化解析和保留，不提供执行运行时，不启动文件、执行 JavaScript 或发网络请求。XFA、脚本运行时按既定范围暂缓。

退出条件：独立读取字段值和导航目标、批注/字段外观对照、跨页共享资源隔离；删除与导入不留下悬空引用，失败不部分提交。

## v0.10 显式结构与可选内容

标准入口：第 14 章 Document interchange，以及第 8 章的可选内容规则。

分为 A Marked Content/结构读取、B 结构写入及维护、C 可选内容。

- 结构树、ParentTree、RoleMap、MCID/MCR/OBJR 关系、Artifact、ActualText/Alt 和适用版本的结构命名空间。
- 提供显式阅读顺序、段落/标题/表格结构的访问和构建接口；没有标签时报告缺失，不推断一个“正确”结构树。
- 页面复制、删除、内容修改时维护已支持的结构引用；无法维护的操作拒绝，不沿用旧 MCID 造成错误关联。
- OCG/OCMD、默认配置及声明支持的可见性规则；渲染与提取可显式选择配置，隐藏内容不等于被删除。

退出条件：独立解析结构关系、标签与内容对应、ActualText 提取、图层组合渲染和保存重开。支持标签机制不自动等于 PDF/UA 合规；视觉结果不代替结构验证。

## v0.11 保存与安全扩展

2026-10-17，基于 `c26f243` 的[分阶段实施计划](releases/v0.11.md)已完成 V11-00～13 的限定范围验收。加密增量、历史验签、层级签名字段/Unicode 外观、DocMDP/FieldMDP 及受控填值/签署/Square 更新已收口；最终完整工作区 85 组、1,501 项通过。实际状态、独立与视觉证据以[验收记录](releases/v0.11-acceptance.md)为准，普通签名来源保护未移除，标准允许但未开放的组合仍明确拒绝。

标准入口：第 7 章的文件结构/加密和第 12 章的数字签名。

分为 A 加密保存、B 签名读写、C 修改约束。进入本版前重新冻结算法和授权矩阵。

- R6 加密增量保存的字符串/流、对象流、ID、Encrypt、原字节和多级 Prev 契约；保持默认保存不移除保护。
- 已评估旧版 Standard handler 的读取需求，本版决定 R2/R3/R4/R5 暂不纳入解密兼容，并保留明确拒绝；不提供弱算法新建加密。公钥加密作为独立后续里程碑。
- 对已有签名提供明确的结构、覆盖范围和 CMS 密码学结果；按选定算法扩展 RSA-PSS/ECDSA，提供可见签名外观及多签追加。
- 解释声明支持的 DocMDP/FieldMDP 约束并限制修改；多签必须分别验证每个已签 revision 和本次变更，不能仅确认旧字节仍在。
- 私钥、证书信任根、网络撤销和时间戳服务交给调用者/外部提供者；核心保留结构和验证结果接口。

退出条件：独立加解密和严格验签、覆盖字节篡改、签后变更/授权负例、旧签名不受新签破坏、准备令牌和预算失败重试。加密签名组合、PAdES/LTV 和完整信任服务不自动随本版开放。

退出条件：每个范围内标准条目都能追溯到实现、公开入口、样本和读写/渲染/编辑证据；未覆盖项明确分类。不存在“v0.12 结束即所有 PDF 都兼容”的承诺。

## 已确认暂缓的能力

2026-10-14 确认：以下能力不列为 v0.6～v0.12 的近期必选项，保留后续专题入口。

| 暂缓实现 | 仍需遵守的边界 |
|---|---|
| 3D、RichMedia/视频/音频 | 已有对象尽可能保留，无法解释或迁移时明确报告 |
| JavaScript、自动启动/联网动作、XFA 执行 | 核心只提供声明范围内的解析/保留；不自动执行程序或请求网络 |
| 陷印、网点、精确专色等专业印刷功能 | 基础颜色/透明度继续做，不宣称精确印刷生产效果 |
| 页面切换效果、高级组合包和地理空间 | 不作为普通文档读写与交互的退出条件 |
| 线性化输出 | 普通全量和增量保存必须正确，线性化另行立项 |
| 时间戳、LTV、完整在线证书信任服务 | 基础签名结构/完整性仍属于核心，信任和网络策略交给外部 |
| 所有字体格式的子集生成 | 保留现有静态子集能力；优先正确读取、绘制和合法嵌入，不要求全格式子集器 |

暂缓不是删除已有实现，也不是允许静默丢弃结构。未支持的解释/编辑组合明确拒绝；“原样保留”不等于“执行语义已支持”。这些能力不影响 v0.6 的内联图像、JPX/JBIG2 读取目标。

PDF/A、PDF/UA 和 PAdES 的专门符合性另建规范及验证矩阵。基础结构支持、现有加密签名能力或一次第三方检查不能代替这些符合性结论。OCR、无标记表格识别、智能脱敏、自动重排与格式转换属于上层路线，不阻塞 PDF 核心交付。

## 每版共同验收

1. 冻结标准版本、章节、输入组合、公开 API、读/写/渲染/编辑矩阵和明确拒绝场景；标准及依赖快照可追溯。
2. 合成边界样本与至少两类独立生产者样本配套；记录来源、许可、生成命令、hash 和预期语义，不只测试本库创建的文件。
3. 保留旧功能；修改后重开、对象引用/流 Length/版本、共享隔离、事务、失败输出和预算边界均有正负例。
4. 按能力选择独立验证：qpdf/pikepdf 检查结构，MuPDF 检查文本/图像/渲染，FontTools 检查字体，签名使用独立验证器。工具缺失属于未验收，不是通过；不强制 Poppler。
5. 渲染新增样本同时核对几何/颜色/Unicode 或标签语义，并逐页视觉复核；提前确定容差，不能验收时选择性放宽。
6. 先定向、再阶段集成，最终冻结源码跑完整工作区；分开记录编译、进程启动和测试正文耗时，慢测不靠 ignore 收口。
7. 本版公布源大小、对象/像素/字形等工作量、耗时和 tracked allocation/RSS 两类内存口径；预算覆盖不到的原生/常驻分配明确说明。
8. 记录已知差异和不支持项，更新支持矩阵/指南/CHANGELOG 后才结束该版本。fuzz 继续暂缓；发布、标签和推送单独执行。

工期在每版源码盘点后按缺口重估，不用功能条目或测试数量推算完成百分比，也不在总路线中承诺统一交付日期。
